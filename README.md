# BODYHEALING

A responsive Scottsdale massage and bodywork website built with Vite and vanilla JavaScript. The original reference photos, typefaces, and visual textures are stored under `public/`.

## Development

```sh
npm ci
npm run dev
```

## Production build

```sh
npm run build
```

The static site is written to `dist/`. Booking calls to action open the accessible inquiry dialog; form submission prepares an SMS to BODYHEALING at `(602) 366-5298` in the visitor's messaging app, where they can review and send their request. The form does not make a booking or transmit data to a server.
